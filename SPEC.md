# SPEC — переделка UI (для новой сессии)

Состояние на 2026-09-01, ветка `arena/01a02c5c-remotecontrol` (PR #1).
Кодовых правок по этой спеке ещё не было — только договорённости.

## Суть
Бэкенд (ASP.NET Core, сервисы, WS-стрим, DDC/CI) — **оставить**.
UI — **переписать** в единый декларативный движок: конфиг → вкладки →
разделы → типизированные элементы. Полный create/delete/edit для всего.
Сейчас в index.html живут 3 конкурирующие парадигмы вёрстки
(статические секции / free-form гейм / виджеты) — это корень текущих болей.

## Требования

### 1. Типы элементов (все типовые, добавлять/удалять/редактировать)
- button: клавиша / комбо / API; режимы click / hold / repeat(N, интервал)
- touchpad 2 оси (джойстик / мышь), сенси, edge-зоны
- скроллбар (1 ось)
- slider (volume/brightness/zoom/fps/quality), toggle (power/wg), input (текст)
- sequence (макрос: шаги key/combo/type/pause с задержками)
- (в будущем) вьюпорт стрима как элемент: растянуть окно стрима на фон вкладки и т.п.
- Встроенные элементы гейма (Camera, Stick, Scroll, кнопки) — тоже типовые:
  редактируемые/удаляемые наравне с кастомными

### 2. Game
- Двойной тап = «изменить / удалить» (без дублирующего resize, без prompt())
- Edge-зоны: размер в **пикселях**, не в процентах (ровно на неквадратных пэдах)

### 3. Настройки
- Баг: чекбокс edge zone применяется только на время нахождения на вкладке
  и не персистится; визуально зона рисуется даже при off — исправить
- Сенси/edge-зоны — глобально (мышь/стрим), как сейчас
- General: редактор appsettings + рестарт сервера — сохранить
- Вкладки: скрытие / перенос в дропдаун ⋯ — сохранить (и расширить до
  «создание разделов» в рамках декларативного движка)

### 4. Stream
- Всё через тот же «полный редактор» (кнопки/тачпады/вьюпорт)
- Поддержка **и портретной, и альбомной** ориентации
- Сохранить: рвение сессии при скрытой вкладке, latest-frame, плавный
  client-side зум (коммит в конце жеста), FPS, пресеты качества, fullscreen

### 5. Профили / масштабирование
- Базовая схема: позиции элементов — **% вьюпорта**, размеры — **px**
- Профили раскладки per-устройство (определение по IP/UA):
  редактирование пишется в профиль «текущего» устройства,
  fallback на дефолтный профиль
- Цель: на двух разных устройствах элементы там, где настроены

### 6. Monitor
- Оставить как есть (ControlMyMonitor + кэш/ретраи/подавление чтений)
- Прямой DDC/CI (dxva2) — **не делать** (решение пользователя)

## Практика
- Сборка: Windows only (net8.0-windows). В песочнице билд не поднять —
  юзер собирает и тестирует. JS чекать node --check, HTML — balance-проверкой.
- API уже готово под конфиг: GET/POST /api/ui (ui.json, LocalApplicationData\RemoteControl),
  /api/system/config, /api/system/restart (--restart-delay)
- Баги текущего состояния — в BUGS.md (раздел «после коммита 3»)
