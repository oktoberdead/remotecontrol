# SPEC — переделка UI (для новой сессии)

Состояние на 2026-09-01, ветка `arena/01a02c5c-remotecontrol` (PR #1).
Кодовых правок по этой спеке ещё не было — только договорённости.

## Суть
Бэкенд (ASP.NET Core, сервисы, WS-стрим, DDC/CI) — **оставить**.
UI — **переписать** в единый декларативный движок: конфиг → вкладки →
разделы → типизированные элементы. Полный create/delete/edit для всего.
Сейчас в index.html живут 3 конкурирующие парадигмы вёрстки
(статические секции / free-form гейм / виджеты) — это корень текущих болей.

## Требования

### 1. Типы элементов (все типовые, добавлять/удалять/редактировать)
- button: клавиша / комбо / API; режимы click / hold / repeat(N, интервал)
- touchpad 2 оси (джойстик / мышь), сенси, edge-зоны
- скроллбар (1 ось)
- slider (volume/brightness/zoom/fps/quality), toggle (power/wg), input (текст)
- sequence (макрос: шаги key/combo/type/pause с задержками)
- (в будущем) вьюпорт стрима как элемент: растянуть окно стрима на фон вкладки и т.п.
- Встроенные элементы гейма (Camera, Stick, Scroll, кнопки) — тоже типовые:
  редактируемые/удаляемые наравне с кастомными

### 2. Game
- Двойной тап = «изменить / удалить» (без дублирующего resize, без prompt())
- Edge-зоны: размер в **пикселях**, не в процентах (ровно на неквадратных пэдах)

### 3. Настройки
- Баг: чекбокс edge zone применяется только на время нахождения на вкладке
  и не персистится; визуально зона рисуется даже при off — исправить
- Сенси/edge-зоны — глобально (мышь/стрим), как сейчас
- General: редактор appsettings + рестарт сервера — сохранить
- Вкладки: скрытие / перенос в дропдаун ⋯ — сохранить (и расширить до
  «создание разделов» в рамках декларативного движка)

### 4. Stream
- Всё через тот же «полный редактор» (кнопки/тачпады/вьюпорт)
- Поддержка **и портретной, и альбомной** ориентации
- Сохранить: рвение сессии при скрытой вкладке, latest-frame, плавный
  client-side зум (коммит в конце жеста), FPS, пресеты качества, fullscreen

### 5. Профили / масштабирование
- Базовая схема: позиции элементов — **% вьюпорта**, размеры — **px**
- Профили раскладки per-устройство (определение по IP/UA):
  редактирование пишется в профиль «текущего» устройства,
  fallback на дефолтный профиль
- Цель: на двух разных устройствах элементы там, где настроены

### 6. Monitor
- Оставить как есть (ControlMyMonitor + кэш/ретраи/подавление чтений)
- Прямой DDC/CI (dxva2) — **не делать** (решение пользователя)

## Практика
- Сборка: Windows only (net8.0-windows). В песочнице билд не поднять —
  юзер собирает и тестирует. JS чекать node --check, HTML — balance-проверкой.
- API уже готово под конфиг: GET/POST /api/ui (ui.json, LocalApplicationData\RemoteControl),
  /api/system/config, /api/system/restart (--restart-delay)
- Баги текущего состояния — в BUGS.md (раздел «после коммита 3»)

## Статус: волна 1 реализована (2026-09-01, ветка arena/01a05bda)
- Game переписан в декларативный конструктор (элементы/слои/opacity/профили per-IP)
- Выбор → только ⤡; двойной тап → ✎/✕ (хэндлы одного семейства, без prompt())
- button: click / hold / toggle / repeat (down → pressMs → up → intervalMs → ...)
- touchpad(X/Y) / scrollbar(1 ось) / joystick; edge-зоны в px, только у touchpad
- sens/lmbTap/edge: глобально в Game Settings + override на элементе (null = глобальное)
- viewport-элемент: политики групп FPS/Q/Zoom (always/button/edit/hidden), жесты вкл/выкл,
  gear — отдельный двигаемый элемент; вьюпорт-виджет доступен и на других вкладках
- Профили: per-host по IP, несколько на хост, lastUsed, новый — по шаблону, ⧉ — копия
- Общее редактирование вкладки Game (system-слой) — из глобальных Settings
- Monitor: старый путь сохранён, ниже добавлен низкоуровневый dxva2 (/api/monitor2/*) —
  РЕШЕНИЕ «не делать» ОТМЕНЕНО юзером в этой сессии; ждём вердикта после теста
- ui.json теперь хранится/отдаётся как сырой JSON (схему держит клиент)

## Статус: волна 2 реализована (2026-09-01, та же ветка)
- Конструктор распространён на ВЕСЬ веб: вкладки (CRUD/порядок/скрытие/⋯),
  разделы-миниканвасы (CRUD/высота/порядок), элементы в разделах (%-позиции) —
  одна логика редактора (editkit) для Game / страниц / Stream
- Дефолтные конфиги страниц воспроизводят прежние Main/Monitor/Mouse/Keys;
  гибрид: простое — атомами, сложное — builtin-блоками (монитор×2, mousepad,
  live-input, send-text, audio-select, shutdown)
- Старые кастомные виджеты автоматически мигрируют в секцию Custom своей страницы
- Вход в редактор: Settings→Tabs→✏️ И дропдаун ⋯ → «Edit this tab»;
  нелепая кнопка «Edit Game tab (system layer)» выпилена
- Точечные фиксы: хэндлы ⤡/✎/✕ вне body (всегда 100% opacity независимо от
  opacity элемента); кнопка мыши — селект LMB/RMB/MMB; поля ms по режимам
  (click → только длительность (честный down→ms→up), hold/toggle → без полей,
  repeat → длительность + интервал); системные элементы (fs/settings/gp)
  добавляются из списка в «Add element»
- Stream: функционально не тронут; его блоки (view/settings/touchpad/buttons/
  input/quickkeys) переставляются/ресайзятся с сохранением per-orientation
  (portrait/landscape независимо; Reset — возврат к дефолтному flex)
- Смоук: tools/smoke — 47 проверок, все зелёные

## Статус: волна 2.1 — полишинг (2026-09-01, той же сессией)
- Фикс внешнего вида элементов: убран border-radius:inherit у .ge-body (кнопки
  снова скруглённые), слайдер-элемент — на стилях volume-slider с заливкой
- #pages-root { display:contents } — вернулся скролл всех вкладок-страниц
- Меню ✎ элемента больше не закрывается сразу: действия хэндлов выполняются на
  pointerup, закрытие модалок по фону переведено на pointerdown
- Все window.confirm заменены на rcConfirm-модалку (#confirm-overlay)
- Инструменты редакторов спрятаны за 🛠-кнопку (collapsed по умолчанию),
  страница больше не перекрывается панелью
- Менеджер вкладок: строка [⠿ drag][имя][✏️], всё управление (rename/edit/
  hide/dropdown/delete) в модалке — ничего не уезжает за экран; порядок — драгом
- Stream: редакторные классы/хэндлы снимаются при выходе (вкладка больше не
  рассыпается после открытия/закрытия редактора)

  pagehide/visibilitychange рвут все сессии
- Монитор: nirsoft-путь снесён полностью (сервер /api/monitor/* + MonitorService,
  клиентский блок, миграция чистит blk-monitor-cmm из сохранённых конфигов);
  slider brightness / toggle power переведены на /api/monitor2/*
- sys-fs на страницах: опции Lock landscape (default on) и Hide top bars
  (default on) — фуллскрин с альбомной ориентацией и скрытием шапки/вкладок
- Убраны дубли заголовков в блоках live-input/send-text
- Смоук: 59 проверок, все зелёные
